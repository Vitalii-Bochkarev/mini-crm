Mini CRM

Учебный проект CRM-системы, разработанный на ASP.NET Core для демонстрации навыков Backend-разработки.

Технологии

- ASP.NET Core (.NET 10)
- Entity Framework Core
- PostgreSQL
- JWT Authentication
- Minimal API
- React + Vite
- Git & GitHub

Реализовано

- JWT авторизация
- Управление пользователями
- Управление ресторанами
- Управление сотрудниками
- Связь Restaurant → Employees
- Swagger UI

Структура проекта

Backend:
- ASP.NET Core Minimal API
- Entity Framework Core
- PostgreSQL

Frontend:
- React
- Vite

Цель проекта

Проект создаётся как портфолио для позиции Junior .NET Backend Developer.

В дальнейшем планируется добавить:

- Поиск
- Пагинацию
- Dashboard
- Refresh Tokens
- Docker
- Логирование
- Unit-тесты

Статус проекта

В активной разработке.
